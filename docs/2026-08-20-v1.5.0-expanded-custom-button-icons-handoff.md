# v1.5.0 expanded custom Button icons handoff

Date: 2026-08-20
Target release: v1.5.0
Task size: bounded
Purpose: input for a later specification and implementation-plan session

## Goal

Expand the icon choices shown when a user creates a custom Button label from
the current 8 reviewed Lucide icons to 24. This release should only expand the
built-in custom-label icon catalog. Importing images and the persistent **My
Icons** library belong to the separate v2.0.0 task.

## Current behavior

- `src/features/quick-panel/model/button-labels.ts` owns the canonical custom
  icon choices and their stable IDs.
- `CustomButtonIconDialog` renders the current 8 choices in a fixed 4-column,
  2-row grid.
- A custom Button label must have a valid `CustomButtonIconId`.
- The selected Lucide icon is persisted with the Button calibration and is
  shared by Buttons-only and Controls + Buttons.
- The same icon definition reaches calibration chips, Customize preview, and
  1024 x 1024 exports.

## Suggested implementation

1. Append the 16 records to `customButtonIconChoices` without renaming or
   reordering the existing 8 IDs.
2. Add English and Traditional Chinese labels under the existing
   `advancedCalibration` locale namespace.
3. Change `CustomButtonIconDialog` from two hard-coded slices to a data-driven,
   scrollable 4-column grid. Keep icon buttons square and retain the current
   accessibility labels and minimum touch targets.
4. Constrain the grid to the dialog's available height so the title,
   description, and Cancel action remain visible on short phones.
5. Keep the existing Lucide-only model, chip styling, persistence format,
   preview, export, and Button order unchanged.

## Compatibility and persistence

- Existing calibrations must remain valid because the original 8 IDs stay
  stable.
- Adding accepted IDs broadens `isCustomButtonIconId`; it must not reset or
  migrate unrelated calibration or preferences.
- The built-in 30-label catalog and `builtInButtonIconNames` must not change.
- Do not add image paths, imported-icon metadata, or v2.0.0 storage fields in
  this release.

## Automated verification expected from the implementation session

- Assert the exact 24 IDs and order.
- Assert all 24 IDs are unique, valid `CustomButtonIconId` values, and valid
  installed Lucide glyph names.
- Assert the 16 additions do not overlap the 30 built-in Button icon mappings.
- Render all 24 dialog choices and verify accessible labels and selection.
- Verify English and Traditional Chinese keys.
- Run focused Jest suites, full TypeScript, lint, and `git diff --check`.

Manual phone-size, scrolling, and visual QA remain user-owned.

## Out of scope

- Image import or cropping
- A persistent personal icon library
- Original/Tint rendering modes
- Changes to calibration order or geometry
- Changes to Customize settings or exports
- Version or Android `versionCode` edits unless the implementation session is
  explicitly asked to perform release metadata work
