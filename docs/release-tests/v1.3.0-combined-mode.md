# v1.3.0 Combined Mode Manual Test

Minimal release check for the new Advanced **Controls + Buttons** target.
Run this on the exact Play testing build intended for release.

## Scope

This checklist covers Combined mode only. Default, Advanced Controls-only, and
Advanced Buttons-only are independent features and are intentionally excluded
from this focused pass.

A crash, lost Combined calibration, blocked calibration/export, partial export,
or material mismatch between Customize, exported PNGs, and QuickStar is a
release blocker.

## Fixtures

- A fully expanded Quick Panel screenshot containing Controls and Buttons.
- Select **Media player** and **Brightness** as the Controls. This makes their
  visual order differ from their required Good Lock export order.
- Select two Buttons in a known order, preferably with different shapes.
- One detailed background image that makes alignment across panel boundaries
  easy to recognize.

## Focused journey

### Entry and calibration

- [ ] On the first v1.3.0 launch, the Combined-mode announcement is readable,
  shows its image, and **Got it** closes it without navigating. It stays
  dismissed after relaunch.
- [ ] Choose **Advanced** -> **Controls + Buttons**. The target is visible and a
  first-time selection opens its own calibration flow.
- [ ] Import the fixture screenshot and place one green outer rectangle around
  all intended Controls and Buttons.
- [ ] Select Media player and Brightness. Confirm that continuing with no
  Control is blocked, then restore the selection.
- [ ] Select two Buttons in a known order. Confirm that continuing with no
  Button is blocked, then restore the selection and order.
- [ ] Set one shared grid. Align Controls first, then Buttons in their selected
  order. Active Controls are purple, active Buttons are blue, and completed
  boxes are orange; every box snaps and stays inside the outer area.
- [ ] Make the active Button overlap a completed Control. **Next** is blocked
  with a clear message; moving it clear allows progress.
- [ ] Final review shows every selected Control and Button once. Save succeeds
  only when no boxes overlap.

### Customize and export

- [ ] Select the detailed background image. Pan and zoom it once; the same image
  placement flows continuously across both Controls and Buttons with no
  panel-specific jump, gap, or second crop.
- [ ] Combined Button image intensity starts at `78%`. Change it and one Button
  identifier setting; the live preview updates the Buttons while Control
  rendering remains appropriate.
- [ ] Export completes as one all-or-nothing run and Result shows exactly four
  items: Media player, Brightness, then the two Buttons in selection order.
- [ ] The four album files are valid `1024 x 1024` PNGs with one contiguous,
  family-aware sequence: `01-control-media-player.png`,
  `02-control-brightness.png`, then `03-button-...png` and
  `04-button-...png`. No file is missing or overwritten.
- [ ] Apply all four files in Good Lock / QuickStar. Image alignment remains
  continuous across both families, and Button intensity/identifiers materially
  match Customize and the exported PNGs.

### Combined persistence

- [ ] Force-close and relaunch the app. Advanced and Controls + Buttons are
  preselected, but both visible selection steps remain available.
- [ ] Re-enter Combined mode. Its outer area, grid, selected Controls, Button
  order, panel boxes, and changed Combined Button intensity are preserved, and
  the saved calibration goes directly to image selection/Customize.
